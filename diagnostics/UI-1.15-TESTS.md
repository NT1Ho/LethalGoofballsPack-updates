# 接收端 1.15.0.0 界面验收

2026-11-01。基线为已发布的 1.14.0.0。接收端使用原构建及发布入口，打包此前验证的诊断插件 0.1.0，DLL SHA256 为 0dd55b510beb160ad731ad937b970e5512e3753d3f4552e26b0f50cc7eb98150。

|范围|结果|
|---|---|
|DiagnosticsUiTests（30 项）|使用真实 V81 旧会话的本地副本。检查首页三个入口及底部余量、真实 WinForms 时间轴、原生截图悬停窗口、节点弹窗、大图、中文摘要、备注和删除恢复。检查无标记、单标记、无截图、128 个集中节点滚动到末项并命中。|
|显示缩放|本机 Windows 原生 120 DPI（125%），核对系统与框架 DPI 相同。对测试窗口发送 WM_DPICHANGED，分别核对 96、120、144、192 DPI 下窄窗口的控件、双行历史记录和导出按钮，保存实际控件渲染图。其他 DPI 属于窗口消息模拟。|
|TimelineTests（42 项）|确认保存门槛、陈旧编辑拦截、崩溃截断尾部、恢复、删除引用过滤、共享性能/日志/自动异常、逐文件 SHA、原始证据不变、密集节点与时间比例。|
|RunningGameTests（18 项）|真实隔离 V81 运行期间，普通入口启动缓存接收端，主界面进入浏览模式，已有历史及活动会话可读。活动会话禁止保存/导出，监控设置中的写入操作禁用，原有 MOD、DLL、配置和更新保护仍生效。关闭接收端后插件继续写入心跳。结束隔离进程后，42 份原有存档/配置文件 SHA 与测试前一致。|

实际检查过首页、时间轴、真实截图悬停框、详情弹窗、空记录、密集滚动和高 DPI 的窗口渲染。初稿在窄窗口下裁掉了底部操作，首页按钮也被撑高，已修复。200% 渲染揭示历史列表第二行裁切，已按字体实际高度修正并重新渲染。运行中测试首次在插件创建会话前读取，改为等待实际写入锁再验证。

界面测试通过控件事件操作，不宣称已完成人工长期体验。原有插件及 ZIP 导出核心沿用同一版本，无新增游戏内采样。真实截图及玩家记录仅留本机。发布后用原版 1.14 接收端程序集调用 ClientLatest、IsNewer、Prepare 与 ValidateRuntime，单独验证原正式通道实际可获取。

正式发布已核实。Release 标签 updater-v1.15.0.0 指向开发分支源码提交 09cd085fdc647a59dafdfdded83395a30ecc69d4。公开 EXE 大小为 615424 字节，SHA256 为 af06f3e38ce42018eb21c1740e06c61281f70c9edf927cca1f70aed6ea6b5257。

使用 SHA 为 dd798ebd…f2fc 的原版 1.14.0.0 程序集，通过原通道验签、识别较新版本、下载、写入隔离缓存并校验缓存运行文件成功。另行回读 GitHub 备用签名清单并验证 COS、GitHub 两端公开二进制，SHA 与已测 EXE 一致。此步骤验证旧端实际获取与准备安装，未在真实 Steam 游戏目录启动常规 MOD 安装事务。

main 由 1a03fef 更新到 f1c73e3，仅 client-update.json 和 client-update.signed.json 有变化。发布前后 COS 整合包清单 SHA 完全一致，GitHub 默认整合包 Release 仍为 V2.0.0。发布记录及测试不包含玩家截图或私人诊断数据。
