# 接收端 1.14.0.0 验证记录 — 2026-11-01

范围：现有诊断 0.1.0 的接收端体验与游戏运行时启动。未修改插件源码、Universal Wrench、游戏玩法或存档。发布授权仅接收端及其必要配套，整合包仍 V2.0.0。

## 已通过

- TimelineTests：47项。跨午夜单调时间顺序、整局比例圆点、密集分行/滚动（128个手动节点）、实际 WinForms 悬停处理加载缩略图/时间/备注、点击选中现场状态和截图；中文备注、待删除撤销、保存后最近删除与恢复；无截图、无标记；首次确认、脏编辑阻止导出、跨窗口陈旧保存/导出拒绝；原始记录不变、共享日志/性能/自动异常保留、过滤重叠窗口的删除引用、导出各文件SHA逐一核对、未固定但有备注会话受清理保护。
- RunningGameTests：16项，真实 V81 隔离副本进程 33100。普通入口实际启动缓存1.14主界面，读取控件文本确认浏览模式和诊断入口；真实会话只读；安装插件、改键、入口替换、接收端更新和MOD更新均拒绝；测试游戏根目录所有文件逐一对比不变。打开关闭诊断窗口后真实插件心跳继续写入。游戏副本使用此前 ES3/Dawn 隔离驱动，测试结束正常关闭；42份真实存档/配置文件与测试前SHA全部一致。
- PostGameTests：10项。真实旧稳定入口的锁释放重试、精确字节升级与备份、幂等、备份回退及再次升级；游戏退出后原Engine用受控网络夹具安装MOD文件并二次检查最新；游戏EXE不变。没有运行真实Steam目录的MOD更新，避免覆盖本机未发布船型候选。
- SelfUpdateTests：33项既有针对性回归，真实缓存文件与模拟子进程应答，包含SHA/版本校验、损坏下载/启动失败/指针写入失败保护、previous回退、损坏缓存恢复、旧迁移协议。不是完整老GUI公网自动升级的替代证据。
- DiagnosticsTests：12项原诊断存储回归通过：安装幂等、DLL备份、配置、活跃会话拒绝、异常尾部恢复、中文备注、白名单ZIP与受保护记录清理。
- 接收端和管理端正式Build.ps1构建通过。界面用实际控件 DrawToBitmap 验证布局，测试通过真实控件处理函数触发悬停/点击，非人工鼠标体验验收。

## 构建与复现

沿用 .NET Framework 4.8 csc + Build.ps1；诊断DLL不重编译，复用已有0.1.0 SHA256：0dd55b510beb160ad731ad937b970e5512e3753d3f4552e26b0f50cc7eb98150。`Build.ps1 -SkipTests -OutputDirectory <输出目录>`，诊断测试引用该目录的接收端EXE；TimelineTests额外引用 System.Windows.Forms / Drawing / IO.Compression / IO.Compression.FileSystem，参数为页面PNG输出路径。RunningGameTests参数：候选EXE、已启动的隔离V81游戏根、证据目录。PostGameTests参数为旧版入口EXE，仅使用临时测试游戏根。禁止将测试驱动分发给玩家。

## 边界与检查中发现的问题

首轮真实界面测试过早读取了句柄创建后、Shown执行前的初始化文字；测试改成等待浏览模式出现，复验16项通过。新增代码初次构建触发C#5不允许catch内await，已将延迟移到catch外。两项均在发布前修正。

没有重跑无关131项整合包发布测试、异地多人或旧版0.1.0性能A/B；插件字节完全未改，沿用此前真实双端/截图/异常恢复和性能记录。接收端新UI不在游戏线程内运行；不声称本轮新测了游戏FPS增益。活动会话只读预览不保证实时刷新，崩溃最后约2秒的原有限制不变。截图缩略图需要磁盘解码；大量历史记录的极端磁盘环境尚未实机长期测试。

“最近删除”无自动过期，避免恢复丢失；含这些标记的整局保持受保护，需玩家导出后主动将整局移至回收站。旧0.1.0数据兼容，但旧1.13界面不了解新删除元数据：整理后应使用1.14导出，不能用旧接收端验证删除筛选。
