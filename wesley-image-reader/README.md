# Wesley 图片中文阅读 0.1.0

适用于 Lethal Company V81、BepInEx 5。把 WesleyImageReader.dll 和 Reader.wri 放在同一个独立插件目录。按 Z 先识别手持物，其次识别准星约 3.5 米内的场景内容，再按 Z 关闭。左右方向键切换中文与英文原图，上下方向键或 Page Up / Page Down 滚动。手册沿用物品原有翻页操作。普通手柄检视和改绑到其他键的原版检视仍可用。

阅读器不写入物品、材质或存档。每台安装的客户端独立显示，无网络消息。禁用或移除整个插件目录即可恢复默认行为。运行时只在按键时解析目标，仅在窗口打开时处理滚动和页码变化。目标有歧义时不显示。

## 资源与构建

用 .NET SDK 构建本目录的 csproj，按需通过 GameRoot 指向装有 BepInEx 的 V81 安装目录。使用 Python 标准库运行 `python prepare.py <用户提供的素材ZIP> Reader.wri`。生成器检查附件的 SHA-256、PNG 尺寸和原图校验值，复用其中 34 张原尺寸中文候选图及 244 张中文阅读图。文件保存原 PNG 字节，读取时只解码当前选择的一张。

Reader.mapping.json 是本版本的显示映射。animation-clips.json 记录了从 V81 已安装资源的 AnimationClip 材质引用中核对的十项补充关联。运行时匹配贴图、尺寸、材质和对象层级，部分机关还使用脚本字段或实际播放的动画。多页手持物读取 Wesley 自身的页码。无可靠的可见命中时保持关闭。内置映射数量与实机覆盖数量分别记录在验证说明中。

源码仓库不含第三方图片；仅有仓库源码不足以重新生成阅读素材，需要另行持有原附件。
