# Wesley 图片中文阅读 0.1.1

独立的 V81 / BepInEx 5 本地阅读插件。将 WesleyImageReader.dll 与同版本 Reader.wri 放在同一插件目录。每个客户端只控制自己的画面。

- **34 张原尺寸中文图**直接显示在原物上，包括五页卡牌手册、门牌、地点牌和四个机关方向标签。沿用手册原有翻页操作。
- **244 份正文**保留现场原图。手持或在约 3.5 米内瞄准已识别对象，按 Z 打开中文正文，再按 Z 关闭。长文可以用上下方向键或 Page Up / Page Down 滚动。

## 实现和维护

资源包仅含 34 张原尺寸中文 PNG、244 份附件提供的中文正文和映射索引。插件按实际材质、贴图、图像格式及尺寸绑定直接显示的素材。方向机关在 Wesley 确定方向并设置材质后更新本地显示。场景加载时分帧应用，并清理离场后的闲置贴图。阅读窗口在打开时才读取正文，目标识别规则复用 0.1.0。禁用插件后还原原版材质引用，磁盘上的原版资源不受影响。

使用 .NET SDK 构建本目录的 csproj，必要时通过 GameRoot 指向安装了 BepInEx 的 V81。运行 `python prepare.py <原始授权交接ZIP> Reader.wri` 生成资源包。脚本核对附件 SHA-256 和候选贴图尺寸。Reader.mapping.json 记录每个 ID 的显示方式和对象关联，animation-clips.json 保留已核实的动画材质关联。仓库不含第三方图片。
