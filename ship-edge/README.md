# 双层船音区交界修复 · 1.0.1

适用范围为 V81，同时安装 mborsh.WiderShipMod 和 MelanieMelicious.2StoryShip 的宽船。插件作为独立 DLL 加载。正式 V2.0.0 的船型、模型、碰撞盒及 Wesley 兼容补丁保持原样。只有正常宽度双层船时不会安装 Harmony 补丁。

原生 AudioReverbTrigger.OnTriggerStay 对每个玩家调用 ChangeAudioReverbForPlayer。它会跳过玩家当前已选的同一个触发器；但在多个触发器重叠时，每个回调都看见上一个触发器改变了选择。反复执行的工作包括船内安全状态检查和按区域更新环境声。在真实故障点对整个方法计时，没有把耗时全部归到某一个内部调用。

本插件参与船体音区和星球 WindTriggers 与船体重叠时的玩家 Stay 回调。当已选区域仍启用、能确认控制器仍与其相交，才比较两个区域。真实离开后立即交给原生流程。船上室外条带优先于覆盖范围很大的室内盒；同角色时，带音频设置的区域优先于仅更新环境或占位的区域，之后比较实际体积和同级顺序。离船条带在玩家身体中心跨入时获得优先权。场景户外音区与船体同时重叠时，如果玩家已经离船、原生条件也不能在此登船，船体不重复夺回场景环境声。

获选音区仍走游戏自己的设置、混响及音量渐变。规则不包含世界坐标或某几个平台名称，不修改怪物、物品、物理碰撞、帧率上限、渲染质量或网络同步方法；转发给预设的特殊触发器保留原生处理。没有每帧扫描整艘船，只在已有触发回调中检查竞争对象。

## 构建与交付

用 .NET SDK 构建 ShipEdgeReverb.csproj，属性 GameDir 指向包含 BepInEx 和 V81 托管程序集的合法安装目录。产物为 ShipEdgeReverb.dll，游戏相对安装路径为 BepInEx/plugins/NT1Ho-ShipEdgeReverb/ShipEdgeReverb.dll。移除这一个额外 DLL 即可撤回修复。诊断插件通过接收端维护，不随 MOD 累计包登记。

1.0.1 同时处理落地和加载期间的甲板与风区。先让两个区域各执行原生设置，在同一个玩家持续接触同一对区域时保留星球环境声。舱内有效音区优先于外部风区，真实离开或开关门仍由原生回调处理。见 MULTIMOON-V81.md。
