# 已验证边界与剩余风险

本轮验证了文件完整性、声明依赖、下载附件/实际 GitHub 二进制 SHA、签名一致、隔离安装与更新事务；没有启动游戏，也没有重新做未变化的 MOD 游戏功能测试。

- 79 个原 manifest 目录、80 个下载来源条目，以及本地组件合并为 82 条 MOD/依赖资料。实际 120 个托管 DLL、64 个 BepInPlugin；不存在重复 GUID 或缺失硬依赖。软依赖可选，不因此补装无关插件。
- 包树 926 文件与完整 ZIP 和当前清单一致。902 个独立 GitHub 二进制实际下载 SHA 校验；COS 全部对象 HEAD 大小/哈希元数据匹配，两个问题 DLL 在 COS 实际下载验证；未为所有 COS 对象重复下载全部数据。
- 本机已有 BepInEx 日志来自含 V81TestChn 的测试运行，出现 DawnLib 可选兼容程序集解析警告、原生音频 DLL 被 .NET 扫描跳过等；不能据此断言正式包新回归，也不为消除可选警告安装额外玩法 MOD。游戏日志不是本轮的新实测。
- H增强版八音盒/机关修复沿用 Terra 已完成的受控验证。异地多人、同一局完整往返地图、长时间所有物品组合仍有未覆盖部分。
- V81 兼容性不是从版本号能自动证明的；尤其旧版插件、复杂尸体/背包/救援交互仍应按实际玩家反馈复测。未发现静态冲突不等于零 BUG。
- COS 与 GitHub 不能保证同时原子提交；部分发布失败应按日志补完，不盲目删除云端版本。GitHub 缓存可能延迟可见。
- 签名提供清单真实性，文件 SHA 提供内容完整性；不等于 Microsoft Authenticode 签名或杀毒信誉。本轮未解决既往 Defender 误报归因/信誉问题，也未关闭防护。
- 早期无 COS/签名支持的历史客户端不能获得新客户端全部保护；需先按正常自更新到当前接收端。
