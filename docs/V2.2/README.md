Steam 原安装实际启动至主菜单，BepInEx 加载四个目标 DLL 及 BetterStamina 1.5.7。退出后五个安装文件逐一与管理端候选 SHA-256 匹配。正式版 V2.1.2 的版本记录仍保留。标准 ZIP SHA-256 为 71d65de0cc39da0d8198471b244a6e6dcfba031d1e35309f4e318326b9b02dd8。

使用真实 V81 敌人 prefab 核对夹角与距离判定，囤积虫在 14.9 米、19.5° 通过，15.1 米或 20.5° 排除；森林巨人在 24.9 米、34.5° 通过，25.1 米或 35.5° 排除。同机独立客户端释放时，房主与客户端均观察到玩家 1 的同一怪物眩晕和原生免疫排除。原版钥匙解锁及持扳手轻按开门均已实测。客户端死亡后包内四件物品保留，负重由 1.338619 回到 1。

Vow 和雾天 Offense 设置了相同参照物与局部浓雾，在不改变原地图参数的情况下截图比较减雾体关闭、开启、再次关闭。游戏内可观测到局部对象，但现场对照不足以确认实际可视距离改善；采样时读取的 Unity VolumeManager 栈报告 volumetric=false，此项不能代表所有相机或天气。没有以全局降低雾量代替局部效果。
