# V1.9 维护交付记录（2026-10-27）

## 实际修复

1. 两个 HookGen DLL 的 V1.6 URL 原先确实返回 404。当前清单改为已验证的历史 Release 地址，使用原密钥重新签名；同时向 V1.6 补入同哈希附件，使旧清单也能继续下载。
2. 修复 GitHub 备份的去重顺序：先筛选此 Release 的文件，再按 SHA 去重。此前 core 与 patchers 两处同内容 DLL 被提前合并，导致漏传。
3. 管理端检查继承的附件引用和最终引用；缺失、错误大小/摘要、引用未公开草稿均阻止发布。无摘要的旧附件须真实下载校验。
4. 发布草稿记录基础清单哈希；版本号没变但清单变了，也会拒绝旧草稿覆盖。
5. 接收端首次接入保留已有 .cfg，缺失配置仍安装。云端未改的配置保持本地值；云端明确改动配置时仍先备份再整文件替换。
