# V2.5.8 本地返修 · 六格持物与电源之心

基于上一份 V2.5.8 电源之心候选与正式 V2.5 的签名基线。兼容组件为 CrewCompatibility 1.0.3，万能扳手为 0.2.14-dev。原始 HotbarPlus 运行文件和六格配置均沿用。

## 六格栏位第一次分歧

Thunderstore 的 HotbarPlus 1.8.6 下载包内，插件自报版本 1.8.5。官方 ZIP 中 DLL 与包内、公司环境两端的原文件 SHA-256 一致。 [HotbarPlus 官方版本记录](https://thunderstore.io/c/lethal-company/p/FlipMods/HotbarPlus/changelog/)

V81 的工具腰带使用槽位 50。旧 HotbarPlus 数字切槽把目标槽与旧槽相减，然后向接收端逐次发送相对滚动。腰带上的原版专业手电切到第一格时，客机只装备一次铲子。房主却从 50 开始收到 50 次反向滚动，依次经过 5、4 等普通槽位后停在空的第五格。第一次分歧来自这条切槽路径。

修复在 HotbarPlus 发送端用原版带目标槽编号的可靠 RPC。保留原版装备、收起和所有权检验以及 HotbarPlus 的六格、快速切换与丢弃后自动选择。滚轮仍使用原版逐格逻辑。手斧的原有装备和收起入口会发出取消事件，错位后的服务器持物校验也会如预期拒绝使用。

## 双端对照

两端从同一个原版专业手电的腰带槽出发。隔离客机临时停用这一个兼容补丁时，双方稳定复现第 5 格与第 1 格不同步。当时夹具只使用了原版手电与铲子。启用修复后，由同一起点切到六个普通格均一致，包含空格。随后夹具加入手斧、扳手和电源之心，完成快速切换及八轮丢弃、自动切槽与拾回。两端的物品网络编号、选中槽和实际持有者以日志为准。

用户录像记录了错位后的表现，缺失最初几次 RPC 的双端日志。复测确认的是一条可重复、与症状一致的首次分歧路径。Barber 恐惧和手斧取消均无需参与即可复现。

## 电源之心

客机负数的 FlashAge 等待实际起点同时保持照明、除雾和显形。冷却结束沿用两次短闪及双音，随后恢复常亮。渐显以原版 HDRP/Lit 的贴图透明裁剪实现。光束中心完整显形，边缘逐渐出现原版的残缺纹理。墙遮挡只影响额外显形，原版近距离效果仍由观察距离决定。
