# V81 整合包玩法与音效候选

以正式 V2.2 为基线。此分支记录候选参数和隔离实机结果。ZIP 包含 13 个差异文件，内容以本地 `SHA256SUMS.txt` 为准。

## 新增

- SelfSortingStorage 1.5.3 使用官方包。默认以 20 Credits 在终端购买 Smart Cupboard，启用默认收纳、堆叠和存档。原版红柜和智能柜是两个独立商店物品。[作者的 1.5.3 说明](https://old.thunderstore.io/c/lethal-company/p/Zigzag/SelfSortingStorage/v/1.5.3/)

## 优化

- OpenBodyCams 3.0.13 关闭 `[ShipUpgrade] Enabled`。飞船监控开局可切换到队友的第一人称。[OpenBodyCams 作者文档](https://github.com/Zaggy1024/LC_OpenBodyCams)
- 老鸟的电击枪停机为 5 秒，自然雷击为 10 秒。电击枪在自然雷击停机期间触发，仍应等自然雷击停机到期。
- 老鸟最大生命值由 EverythingCanDieAlternative 从 15 改为 25 HP。SellBodiesFixed 的老鸟核心基础价格由当前 750–900 改为 500–600 Credits，为原始 250–300 的两倍。终端和业绩使用实际战利品价格及原有收购倍率。

## 修复

- Universal Wrench 0.2.9-dev 将电源之心专属拔电源声提前到强闪后约 0.22 秒。5 秒蓄光、0.8 秒强闪及 30 秒过载按原状态机计时。
- 老鸟短路改用 V81 的 `ShockBeam2` 平稳电流片段，运行中拼接约 4.82 秒循环，在停机结束时淡出。 [Universal Wrench 源码与实机记录](https://github.com/NT1Ho/UniversalWrench/commit/7d6e58cdde7407d8f10f64c10887a19af1b892b8)

## V81 隔离实机

| 项目 | 结果 |
| --- | --- |
| 飞船监控 | 房主和客机在未购天线时，都能实际渲染队友画面。 |
| 老鸟停机 | 原版电击枪和原版天气雷击调用均生效。双端观察到约 5 秒和 10 秒停机并恢复。持续电击不重复续时，电击也没有提前结束雷击停机。 |
| 老鸟受击、掉落和出售 | 双端老鸟初始 25 HP。房主使用铲子实测 25 → 24，原版霰弹枪击杀，两端同步死亡。实际只生成一件核心，Assurance 本次 553 Credits，搬回飞船后在 Gordion 柜台以 100% 收购率完成 553 Credits 的业绩结算。 |
| 智能柜 | V81 + DawnLib 0.9.26 双端购买、房主收纳两件同类废料、客机收纳铲子。重启后客机看到正确道具，房主取回废料并核对 34 与 61 两件价值。旧存档原有 14 件物品在购买后全部留存。 |
| 电源之心 | 两端手持、切换和落地后均检测到一次专属爆发和一次拔电源音效。实际间隔 0.20–0.234 秒。普通闪光在 2.034 秒触发释放声，10.034 和 10.167 秒播放恢复双音。 |
| 老鸟短路音效 | 双端记录到新循环持续播放，停机结束后清理。A/B 影片保留原始音轨，静电音色和接缝听感随候选交给玩家试听。 |

量化结果使用同一台电脑的两个 LAN 进程。柜台及柜子测试由隔离驱动准备实际游戏对象，使用原版或插件的游戏交互入口。柜台验证使用原版最后一天收购率，修正了快速落地脚本给测试存档留下的超长有效期。

H 增强版保留原有插件标识和程序集版本 1.5.1，以 [候选配置与 DLL 哈希](config-delta.json) 区分构建。未找到 NT1Ho 名下的 H 增强版独立远端，源码快照 `dcf28bd826712bfa7411c4f495e31ba7c2bfca60` 与已验证的三文件补丁保存在本地候选目录。
