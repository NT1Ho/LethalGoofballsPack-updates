# Wesley’s Moons 独立简体中文汉化 1.0.0 验收记录

验证范围为 Windows《致命公司》V81、Wesley’s Moons 7.0.18，以及从官方包安装的递归依赖。干净档实测用 BepInExPack 5.4.2305、JLL 1.10.1、LethalLevelLoader 1.7.13、WesleysInteriors 5.0.19 和 CustomStoryLogsFixed 1.6.1。附带的「官方依赖校验」登记全部 26 个包（含主包）的版本、来源和压缩包 SHA-256。

## 游戏内验证

| 项目 | 结果 |
| --- | --- |
| A · 首装 | 从 V81 原版文件和官方依赖建立空配置档，以最终 ZIP 启动至主菜单。Aueser 3.3.2、WesleyDisplayZh 1.3.2 和 WesleyImageReader 0.1.4 全部加载，自带字库生效，四份自定义词库加载 2,043 条精确匹配。此启动没有测试插件。 |
| B · 独立版双端 | 两个独立进程通过原版 LAN 联机。实际着陆加勒特里和格拉塔尔。核对终端中文星球目录、加勒特里简介与《烧焦的便条》，并在运行时核对秘密档案名称及设备提示。两端均在真实地图白板前触发 Z 阅读，显示「资源发现白板」。 |
| B · 录像带与路线 | 房主拾取加勒特里原生录像带并在原生投影机放入，房主和客机都收到因弗尼斯解锁并显示中文字幕。以现有播放器进度核对跳播、暂停、继续与停止。停播后字幕和背景框清除。 |
| B · 广播与字幕样式 | 两端用原版入口进出格拉塔尔厂区。检测当场的原生空间音源，在原有时间点读到谜题的大写 Q。室外的客机无字幕，进厂后显示，离开后两端清除。1024×640 实测文字背景透明度为 50%，背景与物品栏间隔约 9.8 至 11.9 像素。 |
| C · V2.6 兼容 | 从 V2.6 完整候选解到独立副本，保留其现有 LC Chinese Project 和适配。独立 ZIP 与 V2.6 测试副本使用 SHA-256 相同的两个汉化 DLL、六份词库和 Reader.wri。实测中文日志、原生录像带与路线解锁、Z 阅读。实际视频片段经 Unity 播放器验证带声字幕，在 1280×720 检查背景和物品栏间距。 |
| D · 卸载与重装 | 仅移除汉化文件后重新启动，实际终端显示原生英文日志，原有存档标记可读回。连续重装两次后每个汉化插件只加载一次，中文恢复，因弗尼斯解锁及存档标记仍保留。两次安装操作前后测试存档 SHA-256 一致。游戏本身重新进房或退出会运行原有保存逻辑。 |

流程 B 至 D 使用仅部署在隔离副本的测试驱动，通过原版入口和本地输入触发操作。测试只将进度跳到实际片段，广播门槛、谜题条件和路线解锁由游戏本身决定。双端样本与最终播放器的 105 个 C# 方法体比对中，只有 Awake 的启动媒体数量日志调用变化。术语与字幕资源逐字节相同。随后用最终 ZIP 再次实机验证格拉塔尔广播与清除。

## 文件校验与覆盖范围

- 交付 ZIP 通过 CRC、白名单、每个文件 SHA-256 及版本校验。核对安装、使用与移除后 224 个官方原运行文件和资源的 SHA-256。测试使用隔离存档，正式存档的文件校验值和开始前一致。
- 31 段视频、226 个语音播放身份、1,121 条字幕通过现有术语和时间轴检查。文字、终端、任务、物品、图鉴和阅读内容沿用同一资源来源。独立版检测的是代表性真实场景。仍有 3 段视频和 9 个语音身份保留部分覆盖，具体原声或画面疑点继续见 [上一轮逐项记录](https://github.com/NT1Ho/LethalGoofballsPack-updates/blob/fb47980022aeae42faa53072000dc9ed9901f919/wesley/zh/subtitles/validation-v81-1.3.1.md)。
- 原版依赖仍会输出个别重复预制体、物品扫描节点或可选组件警告。WesleysInteriors 自带的两行 Rubber Rooms 文本使用 `LogError`，已核对它们是启动方法固定输出。另有历史使用中记录的原版依赖交互需按实际地图验证。
- 管理器包按其本地 ZIP 文件清单和目录规则核对。本地 ZIP 的真实安装卸载使用文件安装方式，未操作管理器界面。联网验证为同机双端 LAN，跨电脑联网以及全部地图的逐项运行仍待玩家抽查。
