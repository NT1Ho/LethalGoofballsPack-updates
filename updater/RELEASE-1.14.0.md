# 接收端 1.14.0.0

增加故障时间轴、截图悬停预览、现场详情和中文备注。密集标记分行并保留列表选择；自动异常单独查看。

删除节点先进入待删除，可撤销。点击“保存更改”后应用；已删节点可从“最近删除”恢复并再次保存。原截图和现场保留本机直到整局被主动删除。首次导出和后续编辑均需先确认保存；导出只含最后确认保留的节点，保留共享日志、性能数据与自动异常。

修复游戏运行时无法打开接收端。运行中可浏览 MOD、历史、诊断及当前会话已落盘内容；当前会话只读。更新游戏文件、插件安装与配置变更仍需退出游戏。

首次从旧接收端升级请先退出游戏：新版会备份并升级旧入口，之后游戏中即可打开。沿用原正式更新通道，所有使用该通道的玩家均可获取。没有独立测试通道。

诊断插件继续为 0.1.0，嵌入既有已验证二进制，不改变采样或监控行为。接收端首次正常更新可安全安装插件；已有相同 DLL 不重复覆盖。

仅发布接收端，不发布新 MOD 整合包；V2.0.0 与其签名清单不变。详细测试范围、真实游戏验证与限制见源码 diagnostics/TIMELINE-TEST-RESULTS.md。
