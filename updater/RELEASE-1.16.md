# Pack Updater 1.16

从这一版开始，玩家看到的版本使用两段编号。主窗口标题为 Pack Updater · 1.16，游戏运行时的浏览模式、Windows 产品版本、GitHub 发布名称和发布标签都使用 1.16。之后的更新递增第二段，例如 1.17。

自更新协议继续使用可比较的四段程序集版本 1.16.0.0，旧接收端能够沿用原校验方式。此前版本的标签和下载地址保留原格式。

普通更新完成后，主窗口保持打开。故障诊断沿用 Windows 资源管理器的原版搜索图标，导出完成后显示横向确认框。
